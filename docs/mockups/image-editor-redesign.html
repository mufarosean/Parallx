Image Editor redesign

The editor keeps every tool and slider it has today. What changes is how it is laid out: tools become labelled tabs on the panel, the top bar is grouped and fits any width, changes show where they are, presets show what they do, and the photo always sits on neutral grey. Five frames below, then where each current control goes.

What is wrong today

Tools and top bar

  • Edit, Crop And Rotate, Remove and Enhance are four bare icons on a strip at the window's edge; nothing names the tool you are in.
  • The top bar mixes text buttons, unlabelled icons (Copy Edit, Paste Edit), a zoom readout and two view toggles drawn as solid blue squares that outshout Save.
  • Below about 1100px it overflows: the name disappears and the size sits on top of Undo.

The panel

  • A changed slider looks exactly like an untouched one; an edited section looks like any other.
  • Each slider takes two rows (about 43px), so Light alone fills the panel.
  • Auto and Black And White float between the histogram and Light; the clipping markers read as stray squares.

Presets, stage, crop

  • Presets are a text list: you learn what Dusk does by trying it.
  • In light mode the stage turns light grey, which skews how colour reads.
  • Crop shapes hide in a dropdown, straighten is a far-away slider, and the cut-off part is not darkened.

A. Edit

  1. Tools are tabs on the panel (Edit, Crop, Remove, Enhance), labelled, with a dot on tools that hold changes, the same way the clip editor marks its inspector tabs. The strip at the window's edge goes.
  2. Changes show where they are. A changed slider's name brightens, its value turns accent, and a fill runs from rest to the knob. A section with changes gets a dot; closed sections keep it, so you can see Effects was touched without opening it.
  3. One row per slider (name, track, value), as in Lightroom: Light and Colour fit together. Double-click still resets; the value can still be typed.
  4. Section actions in the header: Auto sits on Light, the white balance picker on Colour, Black And White becomes Colour's B&W switch. Eye and reset stay.
  5. Histogram with named clipping. The two corner triangles light when shadows or highlights clip, and the line under it says how much ("Highlights 1.2% clipped"); clicking a triangle shows the clipped pixels on the photo.
  6. Presets show themselves: a small picture of this photo in each look; pointing at one previews it on the stage, clicking applies it. Your own presets sit under Yours.
  7. The edited filmstrip photos carry a dot; the count stays.

Your edits are kept with the photo either way; nothing is lost if you close the tab.
  1. A grouped top bar: Presets toggle and name · Undo, Redo · Compare · Zoom · ⋯ · Save. Every icon button has a label in its tooltip and a shortcut; toggles look like toggles (a soft selected state), never like Save.
  2. Compare is one control with two states, Hold (press \ to see the original) and Split (a handle you drag). It replaces Show Original and the split icon.
  3. Zoom is one control: the percentage opens Fit, 50%, 100%, 200%; the stage keeps a small zoom chip.
  4. ⋯ holds what is used less: Copy Edit, Paste Edit, Save Edit as Preset…, Show Presets, Show Filmstrip, Reset All Changes….
  5. Save is a split button. Save As Copy is the safe main action; Save Over Original… sits in its menu, in red, and still asks first. Disabled, it is plainly grey.
  6. The stage stays neutral dark in light mode (viewer tokens), so colour reads the same in both.

  1. Shapes are chips, each drawn at its proportion, with Swap Orientation beside them. Free stays; Original is the default.
  2. Straighten on the photo: a dial under the stage you drag; the slider in the panel stays for exact values. Drawing a line along the horizon to level it is a later addition.
  3. What is cut is darkened, the frame shows its size in pixels, and corner handles are drawn as corners.
  4. Rotate and flip are one icon row with tooltips; Reset Crop sits in the section header like every other reset.

Build order

  1. Fix the narrow top bar first (the overlap is a bug), with the grouped top bar, ⋯ menu and Save split button.
  2. Panel: tool tabs with dots, one-row sliders, changed marks, header actions, histogram clipping line. New values go in a Tier 3 "Image editor" token block.
  3. Stage: neutral dark in both modes; Compare as one control.
  4. Presets: thumbnails rendered from the open photo (small, cached per photo), hover preview.
  5. Crop and Remove: shape chips, straighten dial, darkened outside; removal rows, brush keys, setup card.
