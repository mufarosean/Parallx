PDF viewer: bringing the rest in line

Built 2026-10-02, all four parts, as drawn here. Two small departures: the outline marks the current section by where the view's top edge is (not just the page), and a document with no outline shows "This document has no outline." on the Outline side and opens on Pages.

The toolbar and the page are already in the house style; the fixes on 2026-10-02 took the dark frame off the page, gave page 1 its top margin, made Ctrl+F open Find and set the current match apart. What follows is the rest: the find bar, the side panels, what happens when you select text, and the highlight panel. Each one is shown today beside a proposal that reuses a part the app already has.

1. Find

Today a full-width strip pushes the page down, with the old input colours. Proposed: the same floating find widget the text editor uses, top right over the page, so Find looks and behaves the same everywhere. pdf.js already supports match case and whole word; the widget's two toggles turn them on.

2. Outline and pages

Today Outline and Pages are two separate panels with two toolbar buttons, old colours, and the current page marked in old navy. Proposed: one panel with an Outline | Pages switch (the same segmented control the Atelier sidebar uses), rows in the house style, and the current section or page marked with the accent. One toolbar button opens it, and it remembers which side you last used.

3. Selecting text

Today every selection pops a 13-row menu over the page, five rows of which are highlight colours. Proposed: a small bubble above the selection, like the one on a canvas page, with the things people do most. Everything else moves to the right-click menu, which shrinks to eight rows with a Highlight submenu.

4. The highlight panel

Opened from the tab beside a highlight. Today: see-through colour dots that turn muddy on the dark panel, an old blue ring and send button, a red Delete link at the bottom. Proposed: solid dots with an accent ring, Delete as an icon button in the panel's top row, the note and the question in the house inputs, and send in the accent.
