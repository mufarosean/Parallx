Worksheets, aligned with the app

Built 2026-10-02, every screen, from this page and the Claude Design canvas "Worksheets Redesign". Where the build differs: Ctrl+1/2/3 for rating were dropped (the app already uses them to focus editor groups, and Ctrl+1 is Excel's Format Cells); the quiz overview keeps its per-row note button; a Problem Bank row's ⋯ holds Quiz This Problem, Star and, for generated items, Delete Item…; Import has a Choose Excel File… button rather than a drop area; the problem sheet's ⋯ holds Dark Sheet, Export to Excel, Open Problem in Its Own Tab, Show in Problem Bank and Reset Work…, and Review in Chat stays as a button under the header once the solution is shown.

Every Worksheets screen redrawn with the parts the rest of Parallx already uses: kit buttons (primary, secondary, ghost, danger), the kit page header, the segmented switch, list rows with actions on hover, the ⋯ menu. One part is new, the filter chip, and it would be registered in the kit so the Atelier and Media Organizer filters can use it too. The data is the screens probe's test bank.

What stays as it is: what each screen does, the order you work in, the light practice sheet (Settings → Sheet appearance), the Dashboard's content and charts.

Build order

  1. Parts: register the filter chip in the kit; swap Worksheets' buttons and headers to the kit (no layout change yet). Copy changes ride along.
  2. Tabs: names and icons.
  3. Home, Quizzes, Summary, Overview: headers, rows with ⋯ menus, the quiz bar's dots.
  4. Bank and New Quiz: chips, the two-column builder, Quiz These….
  5. Problem sheet: rating switch and its shortcuts, labelled Reveal Solution, ⋯ menu.
  6. Import, Generate, Settings: drop area, footer bars, settings rows.

Each step is checked in the app with the screens probe in dark, light and a narrow window before the next.
