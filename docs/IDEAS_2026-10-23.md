### Paste Markdown As Blocks (S, impact 4, time-saved)

When the clipboard holds plain text and no HTML, and the text looks like markdown (a heading, list marker, fence, table or `$$` on any line), run it through the existing lossless `markdownToTiptapJson` and insert real blocks at the caret; ordinary prose stays a plain paste, and Ctrl+Shift+V always pastes plain. Dropping a `.md` file onto a page does the same. In use: an answer copied from Claude Code, a chat reply, or a `.md` note lands as headings, lists, code and equations instead of literal `#` and `-` lines.

Why: The only paste plugin in the editor handles images; `markdownToTiptapJson` is called by the AI tools, buttons and inline AI, never by a paste path. The assessment listed "markdown paste" under missing editing features and it is still missing. The owner moves work between Claude Code and the app daily, so this is a hand-fix repeated every time.

### Images Live As Files, Not Base64 (M, impact 4, debt)

Write every pasted, dropped or uploaded image to `<workspace>/.parallx/canvas-assets/<sha>.<ext>` and reference it from the block by an app-served `parallx-asset:` URL (a main-process protocol the CSP allows, like the one that serves PDFs). Pages migrate lazily: the first open of a page with a `data:` image writes the file and rewrites the block. Markdown and PDF export resolve the asset; AI reads emit `![alt](asset-name)` instead of the bytes. In use: a painting-notes page with six reference photos saves, versions, searches and reads to the model as text, not as megabytes.

Why: Images are inlined as base64 at all three insertion points, kept in every page revision, scanned by `getBacklinks` (`instr(content, …)`), and, because `linkDestination` passes a `data:` URL through unchanged, the whole base64 string goes into the markdown that `canvas_read_page`, Flashcards and Worksheets hand to the model. One screenshot can fill the model's context window; nothing strips it. The assessment flagged this (Architecture 8) and it is unchanged.

### Less Work Before The First Token (M, impact 4, debt)

Three measured per-turn costs removed. One embedding per turn: the context engine embeds the prompt once and hands the vector to both `retrieveContext` and `recallMemories`, instead of each service calling `embedQuery` itself. RAG as soon as the index has rows: the gate switches from 'this launch's full walk has finished' to `vectorStore.getStats().totalChunks > 0`, so a workspace indexed last week answers from its notes on the first turn after boot. ### Find In Files Reads PDFs (M, impact 5, time-saved)

Search stops skipping PDFs, Word files and spreadsheets: a query returns rows per page ("Mack 1994.pdf, page 13") with the matching line, and clicking one opens the PDF on that page with the quote found. It reuses the file locator's cached page texts, so the second search over the same papers is instant. Searching fifteen exam papers for a term becomes one Ctrl+Shift+F instead of opening each PDF and pressing Ctrl+F.
