# Reading anchors

Human-written scenes the reading bench scores on the same rubric as the
model's, so the bar is set by a book and not by the judge's mood. A judge
that gives these a 5 is not a judge to trust on a 5 for the model; a model
within two points of them on the positive criteria is writing like a book.

Fill each section with the text of the scene (a few hundred to a thousand
words), from a public-domain edition (Project Gutenberg). Leave an unfilled
section as it is; the bench skips it. `Strangers: yes` runs the strangers
checklist on it. Keep this file to public-domain text only.
