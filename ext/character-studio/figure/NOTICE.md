# The figure

Everything in this folder is generated by `scripts/bake-character-figure.mjs`.

- **Body, sliders, rig, skin weights:** the MakeHuman data that Anny ships
  (github.com/naver/anny, commit 8f35dc2d, 2026-10-26): base mesh, body
  and modifier targets, default rig and weights, adapted by MPFB2, CC0 1.0.
  The two small mesh edits and the way the body targets combine follow
  Anny's code (Copyright 2025 NAVER Corp., Apache License 2.0); none of its
  code is included.
- **Eyes, eyebrows, eyelashes, hair, teeth, tongue, skins, iris colours:**
  the MakeHuman system asset pack
  (files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip),
  released as CC0 1.0 in September 2020 by Data Collection AB, Joel
  Palmius and Jonas Hauquier. Textures converted to WebP.

Checked against Anny's own cached rig: 103 bones (all but its root, which
Anny places by its own convention), the template and 1,072 blend shapes
agree to within 0.00001 mm.

To rebuild: clone Anny, extract the asset pack, then
`node scripts/bake-character-figure.mjs --anny <anny>/src/anny/data --assets <pack>`.
